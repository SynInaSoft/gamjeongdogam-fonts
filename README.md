# gamjeongdogam-fonts

Korean fonts that the 감정도감 (Emotion Dex) app downloads on demand, served through jsDelivr:

```
https://cdn.jsdelivr.net/gh/SynInaSoft/gamjeongdogam-fonts@v1/fonts/<file>
```
